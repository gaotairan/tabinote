# TabiNote（タビノート） - 旅のしおり Webアプリ ✈️

> **tabiori（旅のしおり）の全機能をブラウザで再現し、Googleカレンダー連携＆Firebase Firestoreによる「常時リアルタイム自動同期」を搭載したモダンWebアプリケーション**  
> PC・スマホ（PWA対応）でどこでも確認可能。オフラインでも動く安心設計。

🌍 **本番公開URL**: [https://tabinote-928f9.web.app](https://tabinote-928f9.web.app)

---

## 🌟 主な特徴と機能

### 0. ☁️ 常時リアルタイム自動同期（Google Cloud Firestore連携）
- **完全な双方向リアルタイム同期**: スマホやPCで編集した予定・持ち物チェック・費用精算が、他端末へ即座に（リロード不要で）自動反映されます。
- **設定不要・即時共有**: アプリを開くだけで本番クラウドDBに自動接続。QRコードをスマホカメラでかざすだけで、瞬時に同じしおりが共同編集モードで開きます。
- **オフライン安心設計**: 電波の届かない地下鉄や飛行機内でも操作可能。オンライン復帰時に自動的に最新状態へ同期されます。

### 1. 📅 Googleカレンダー連携＆しおり自動生成（目玉機能）
- **.icsファイルドラッグ＆ドロップ**: Googleカレンダーからエクスポートした`.ics`ファイルを放り込むだけで、タイトル・日程・日別タイムライン・Googleマップリンク・基本持ち物を自動判定・一括生成！
- **Google アカウント直接連携（OAuth 2.0）**: Google Identity Servicesを使って、指定した旅行期間の予定を直接取得可能。
- **予定テキスト自動解析**: メモ帳の箇条書き（「10:00 東京駅集合」「12:00 清水寺散策」など）を貼るだけでタイムライン化。
- **ワンクリック・サンプルテスト**: 北海道2泊3日サンプルの予定をワンクリックで読み込み、すぐに自動生成を体験できます。

### 2. 🗺️ tabiori（旅のしおり）コア機能
- **旅の概要（Overview）**:
  - 旅行タイトル・サブタイトル・目的地・カバー写真（プリセット/URL）
  - 出発までのワクワクを高める「あと○日」カウントダウンタイマー
  - 参加メンバー一覧（アバター・役割バッジ）
  - 緊急連絡先・合言葉・メモ
  - 旅先の天気予報ダイレクトリンク
- **日別タイムライン（Timeline）**:
  - 日程ごとのタブ切り替え（1日目、2日目、3日目...曜日付き）
  - 移動（電車・飛行機・車・バス・徒歩・船）、食事、観光、宿泊、アクティビティを色分け＆アイコン表示
  - **Googleマップへのワンタップ経路案内リンク**
  - 予定の追加・編集・並べ替え・削除
- **持ち物チェックリスト（Packing）**:
  - カテゴリ別整理（必需品、衣類、電子機器、洗面用具、その他）
  - 誰の持ち物かアサイン可能（全員 / 特定メンバー）
  - 進捗プログレスバー表示＆全完了時の紙吹雪演出！
- **お土産・Wishリスト（Souvenirs）**:
  - 誰に買うか（職場・家族・友人・自分用）のタグ分け
  - 買う場所、目安価格、購入済みチェック、合計予算計算
- **割り勘・費用精算（Expenses & Split）**:
  - 旅行中の支払い記録（支払った人、割り勘対象メンバー、金額、メモ）
  - 合計支出＆1人あたりの平均金額
  - **最小送金回数の精算ルート自動算出**（「AさんがBさんに¥3,000支払う」が一目でわかる！）

### 3. 📱 マルチデバイス・PWA・共有機能
- **スマホ＆PC最適化**: スマホでは片手操作しやすい下部ボトムナビゲーション、PCでは広々としたマルチカラム表示。
- **PWA（Progressive Web App）対応**: スマホの「ホーム画面に追加」でネイティブアプリのように全画面で起動。
- **完全オフライン対応**: データはLocalStorageに自動保存されるため、飛行機内や山奥の電波が届かない場所でも閲覧可能。
- **QRコード共有 / JSONエクスポート**: スマホのカメラでQRコードを読み取って同じしおりを確認可能。データのバックアップや復元も容易です。

## 🚀 ローカルでの起動方法

```bash
# 依存関係のインストール（初回のみ）
npm install

# 開発サーバーの起動
npm run dev
```

起動後、ブラウザで `http://localhost:5173/` にアクセスしてください。

## 🌐 スマホやPCでどこでも確認するためのデプロイ方法（無料）

GitHubにプッシュした後、以下の無料ホスティングサービスと連携することで、世界中どこからでもスマホやPCでアクセスできるようになります。

### 方法A: Vercel（おすすめ・最も簡単）
1. [Vercel](https://vercel.com/) にGitHubアカウントでログイン
2. 「Add New...」→「Project」を選択
3. GitHub上の本リポジトリを選択して「Deploy」をクリック
4. 数十秒で公開URL（例: `https://tabinote.vercel.app`）が発行されます！スマホのブラウザで開いて「ホーム画面に追加」すれば完了です。

### 方法B: GitHub Pages
1. `npm run build` でビルドされた `dist` フォルダを公開するか、GitHub Actions で自動デプロイを設定します。

## 🔑 Googleカレンダー直接連携（OAuth）の設定方法（任意）

手軽に使う場合は、設定不要の「**.icsファイル取り込み**」タブをご利用いただけます。  
Googleアカウントと直接連携したい場合は、以下の手順でGoogle Cloud ConsoleからClient IDを取得できます：

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスし、新しいプロジェクトを作成
2. 「APIとサービス」→「ライブラリ」から **Google Calendar API** を有効化
3. 「OAuth 同意画面」を設定（ユーザータイプ: 外部、テストユーザーに自身のGmailを追加）
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」を作成
   - アプリケーションの種類: **ウェブ アプリケーション**
   - 承認済みのJavaScript生成元: `http://localhost:5173` （およびデプロイ後のURL）
5. 発行された **Client ID** をアプリ内の「Googleカレンダー連携」モーダルに入力して保存
